# VeriHire v2 - Evaluation Harness

This directory is reserved for Milestone 4 (M4: Evaluation and explanations).

Planned components:
- Labeled queries and candidate datasets
- Baselines: Keyword / BM25, Embeddings-only, Hybrid (RRF), Full pipeline (Retrieval + Evidence + LLM)
- Metrics: NDCG@10, Precision@10, Latency, LLM invocations per run
- Threshold calibrations for candidate match labels
