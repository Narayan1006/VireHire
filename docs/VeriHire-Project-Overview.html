Executive Summary

VeriHire AI replaces keyword-matching ATS systems with evidence-backed hiring intelligence.

Traditional Applicant Tracking Systems ask: Does this resume contain the right words? VeriHire asks: Can this person actually do the job?

Recruiters upload a candidate CSV, paste a job description, and receive a ranked shortlist where every score is backed by verified GitHub repositories, LeetCode activity, and AI-generated recruiter summaries.

Key Capabilities

  • CSV dataset ingestion — recruiters upload their own candidate pool (up to 50 MB)
  • Semantic matching — ChromaDB + sentence-transformers retrieve top candidates by meaning, not keywords
  • Evidence verification — GitHub, LeetCode, and Codeforces APIs validate claimed skills
  • LLM reasoning — Groq (Llama 3.3 70B) generates evidence-only hiring summaries
  • Verdict system — automatic HIRE / REVIEW / REJECT classification with export

Scoring & Verdict Logic

PR Score (Performance Rating)

PR Score = GitHub × 0.4 + DSA × 0.4 + Consistency × 0.2

GitHub score (0–100) reflects repo quality, architecture, language diversity, and activity. DSA score (0–100) comes from LeetCode/Codeforces ratings and problem-solving patterns. Consistency measures regular coding activity over time.

Final Composite Score

Final = Layer1 × 0.2 + Layer2 × 0.6 + Layer3 × 0.2
